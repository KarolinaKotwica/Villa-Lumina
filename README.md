## About

A luxury real estate showcase inspired by viral immersive websites like MARAVILLA.  
The main effect: scrolling = moving through the property — just like Apple product pages.

## Tech Stack

- **HTML5 / CSS3 / Vanilla JavaScript** — no frameworks
- **GSAP + ScrollTrigger** — scroll-driven animations
- **Canvas API** — image sequence synced to scroll position
- **Lenis** — ultra-smooth scroll
- **SVG** — architectural annotations that draw on scroll
